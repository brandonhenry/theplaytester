# Free game polls and results

Polls are exclusively on [theplaytest.io](https://theplaytest.io). A creator can post free polls for a game they own **after at least one successfully funded publication of that game**. The playtest does not have to remain open. An unfunded draft is insufficient. No recurring subscription or extra poll payment is required by the current workflow.

## Prepare and publish

1. Open the creator workspace or the eligible game’s page and choose **Create poll**.
2. Select the correct game from the custom dropdown. It defaults to the latest eligible publication. When several games are plausible, identify the game rather than accepting the default silently.
3. Clarify the decision the poll should inform, question, format, options and any provided assets. If the request is “ask whether the UI is better”, ask which versions to compare and obtain the images; do not invent screenshots.
4. Draft a neutral question (5–240 characters), optional description (up to 1,000), and **2–6 distinct labeled options** (each 1–160 characters).
5. Choose one format: text, image or video. A text poll has no attachments. Image/video polls require matching media on the question or choices; do not mix formats. Use approved assets and explain that poll media is public, even if the game build is private.
6. Current uploads: JPG/PNG/WebP up to 5 MB; MP4/WebM up to 50 MB. External media requires HTTPS; video links must point to a playable media file. A YouTube watch page is not an MP4 file for a poll attachment.
7. Review the final game, question/options and public media. Publish within the request’s authorization and verify the poll ID, appearance and count on that game’s page.

If there is no eligible publication, explain the gate and prepare the poll draft. Do not fund a listing just to unlock polls without the owner’s approval and budget. Do not misrepresent a poll as a paid playtest.

## Results, changes and closing

Verified members vote once for free; duplicate votes are not allowed. Do not vote as the user unless explicitly instructed which option to choose; never simulate votes. Public results contain aggregate counts, not voters’ identities. Do not infer demographics or motives from an anonymous vote total.

Refresh the poll whenever the owner wants results, and follow **Older polls**/pagination when needed. Polls remain on the game’s page after recruitment closes. “Close voting” freezes that poll; closing a listing is separate. Published question/labels do not have an edit endpoint. If the owner needs corrected wording, explain the limitation, close the existing poll only if authorized, and prepare a replacement.

Report question, option labels, counts, percentages, total votes, open/closed status, fetch time and change since the last successful baseline. At zero votes there is no leader. Report ties as ties. One vote is one response, not a representative market study; frame design conclusions in proportion to the available evidence. Distinguish the absolute leader from which option gained most new votes since the last report.

Share a game link `https://theplaytest.io/#game/GAME_ID`; no standalone `/#poll/...` route is documented. Invite interested users through authorized channels only. Do not post the game/poll publicly outside Firstplay merely because you created it.
